# 展示视频分镜脚本

> 归零 DigiLegacy · 参赛展示视频
> 目标时长：3 分钟（180 秒）——国创赛/挑战杯通用的上限区间，剪出后按各赛事要求截取

> 节奏：每 15-20 秒一个信息点；画面与配音严格对位

## 待补录屏清单（screen recording）

1. 仪表板 → 顶部「安全检查」按钮点击反馈（10-15 秒）
2. 资产发现：完整走一遍问卷并出现推荐结果（30 秒，加速 2 倍处理）
3. 继承报告导出：点导出 → 浏览器打开 HTML 报告（15 秒）
4. （可选）安装包双击安装过程，突出「体积小、秒装」

## 合规红线（制作时必须遵守）

1. 界面/报告内一律使用虚构演示数据：人名用「张三/李四」，手机号用 130-0000-0000 类占位
2. 新闻截图保留原出处水印/角标，不裁剪来源
3. 不使用真实遗属画面的表情特写；剧情段用物件（手机、相册）而非人脸叙事
4. 背景音乐选用可商用/免版权曲库，保留授权截图
5. 各赛事如有「必须含团队实拍/项目实拍」要求，F1 已预留；具体以届官方通知为准
