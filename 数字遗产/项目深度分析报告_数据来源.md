## 二、核心平台继承政策（支撑数据库条目）

### 2.1 微信 — 最难继承的超级App

| 政策 | 来源 |
|------|------|
| 微信账号本身不可继承（用户仅有使用权），仅可导出聊天记录 | 微信用户协议；无数继承案例证实 |
| 连续180天未登录账号将被平台收回 | 多家媒体报道（含微信员工向陈晔提供的清单确认） |
| 微信以"涉及个人隐私"为由拒绝人工介入找回已故用户账号 | 微信公众号"去世父亲微信账号被收回"，2025年（陈晔案例，父亲去世10年后被销号） |
| 陈晔收集11条信息（注册时间、最后使用设备等）仍被拒绝 | 同上 |
| 微信公众号"个人类型"不支持继承——周某诉平台案 | 微信公众号"亲人去世后，微信与支付宝余额能继承吗？"引用法律界人士，2025年 |
| 公众号平台提出迁移调解方案（周某案） | 同上 |
| "往亲属账号每月转1分钱可能避免回收"（民间方案） | 网友支招，同上 |

**真实案例：**
> 陈晔的父亲于2015年12月18日猝然离世。2025年，父亲去世10年后，微信账号被平台悄然收回。陈晔曾通过朋友圈评论找到父亲头像，发现已成为"wxid-"开头的初始昵称，"该用户不存在"。微信方面以"涉及个人隐私"拒绝人工介入。（来源：微信公众号《女子大哭：父亲去世10年后，微信被销号！》2025年）

### 2.2 支付宝 — 财产量最大的数字钱包

| 政策 | 来源 |
|------|------|
| 参照银行存款管理，需提供死亡证明、继承公证书、继承人身份证 | 支付宝客服公开指引；2025年银行新规明确 |
| 余额、余额宝资金可依法继承 | 最高法"数据、网络虚拟财产纠纷"案由（2026年1月施行）提供司法路径 |
| 5万元以下走简易继承程序 | 2025年银行新规 |

### 2.3 腾讯游戏 — 有明确判例支撑

| 政策 | 来源 |
|------|------|
| 北京石景山法院：87个游戏账号继承案，判令游戏公司配合办理实名变更 | 凤凰网·惠诚律所，2025年 |
| 法院认定：账号载体所有权归平台；使用权/收益权等财产性权益归用户 | 同上 |
| 平台格式条款"不得继承"被认定无效 | 同上 |
| 经营性账号财产权益原则上可继承 | 同上 |
| 87个账号判例：古先生身故，母亲主张继承实名认证账号，平台拒绝 | 同上 |
| 长沙望城区法院：游戏账号外借被封10年，判赔1358元（账号价值1940元） | 腾讯新闻，2025年9月 |
| 游戏账号经官方评估皮肤资产18970源晶点+430，市场价值1940元 | 同上 |

**真实案例（真实判例）：**
> 22岁的"00后"冯先生为回馈姐姐照料，在遗嘱中将全部工资存款及使用7年的游戏账户作为数字遗产进行分配，成为中华遗嘱库"十大典型案例"之一。（来源：司法部官网，2026年4月7日）

### 2.5 各平台继承难度评级（基于上述数据）

| 平台 | 难度 | 依据 |
|------|------|------|

| 微信（余额） | 中等 | 财产权益受法律保护 |

## 三、支撑论证的关键法条

1. 《民法典》第127条：确立虚拟财产法律保护原则
2. 《民法典》第1122条：遗产为死亡时遗留的个人合法财产
3. 《民事案由规定》2026年修正：新增"数据、网络虚拟财产纠纷"一级案由
4. 北京石景山法院2025年判例：平台格式条款剥夺虚拟财产继承权无效
5. 2025年《简化小额存款继承流程指导意见》：5万元以下免公证
